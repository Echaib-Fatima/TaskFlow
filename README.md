# ✨ TaskFlow

### Organize. Plan. Achieve.

**TaskFlow** is a simple and responsive task management web application designed to help users organize their daily tasks, manage their activities, and improve their productivity.

---

## 📌 About the Project

TaskFlow is a front-end web application developed using HTML, CSS, and JavaScript. It provides an intuitive interface that allows users to manage their tasks and customize their experience.

## 🚀 Features

- **User Registration:** Create a new account.
- **User Login:** Access your personal account.
- **Task Management:** Add, edit, and delete tasks.
- **Dashboard:** View and manage your tasks.
- **Task Tracking:** Track completed and pending tasks.
- **User Profile:** View and update personal information.
- **Settings:** Customize application preferences.
- **Multilingual Support:** English, French, and Arabic.
- **Responsive Design:** User-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## 💻 Installation and Execution

### 1. Clone the Repository

```bash
git clone https://github.com/Echaib-Fatima/TaskFlow.git
```

### 2. Open the Project

Open the project folder using Visual Studio Code.

### 3. Run the Application

Open the `index.html` file in your web browser.

You can also use the Live Server extension in Visual Studio Code.

## 💾 Data Storage

TaskFlow uses the browser's Local Storage to store application data locally.

Data is stored in the current browser and is not automatically synchronized across different devices.

## 🔒 Security Note

This project is developed for educational purposes. Authentication and data storage are handled on the client side. A production application would require a secure backend, database, password hashing, and server-side authentication.
